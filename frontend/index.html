CodeSnap Language Specification & Context-Free Grammar

1. Context-Free Grammar (CFG in BNF)

<Program>          ::= 'START' <StatementList> 'STOP'
<StatementList>    ::= <Statement> <StatementList> | ε
<Statement>        ::= <VarDeclaration> | <Assignment> | <PrintStatement>
                     | <IfStatement> | <WhileStatement> | <ForStatement>
<VarDeclaration>   ::= 'LET' IDENTIFIER '=' <Expression>
<Assignment>       ::= IDENTIFIER '=' <Expression>
<PrintStatement>   ::= 'PRINT' <Expression>
<IfStatement>      ::= 'IF' <Expression> <StatementList> [ 'ELSE' <StatementList> ] 'END'
<WhileStatement>   ::= 'WHILE' <Expression> <StatementList> 'END'
<ForStatement>     ::= 'FOR' IDENTIFIER '=' <Expression> 'TO' <Expression> [ 'STEP' <Expression> ] <StatementList> 'END'
<Expression>       ::= <LogicalOr>
<LogicalOr>        ::= <LogicalAnd> ( 'OR' <LogicalAnd> )*
<LogicalAnd>       ::= <LogicalNot> ( 'AND' <LogicalNot> )*
<LogicalNot>       ::= 'NOT' <LogicalNot> | <Comparison>
<Comparison>       ::= <ArithmeticExpr> [ ( '==' | '!=' | '<' | '<=' | '>' | '>=' ) <ArithmeticExpr> ]
<ArithmeticExpr>   ::= <Term> ( ( '+' | '-' ) <Term> )*
<Term>             ::= <Factor> ( ( '*' | '/' | '%' ) <Factor> )*
<Factor>           ::= ( '+' | '-' ) <Factor> | <Primary>
<Primary>          ::= INTEGER | FLOAT | STRING | 'TRUE' | 'FALSE' | IDENTIFIER | '(' <Expression> ')'

3. Theory of Computation Alignment

This mini-project demonstrates key foundational TOC concepts:

  • Regular Expressions & Finite Automata: Lexical tokens (Identifiers, Literals, Operators) are regular languages recognized by Deterministic Finite Automata (DFA).
  • Context-Free Grammars: CodeSnap's syntax is defined using context-free productions and recognized by a recursive descent parser (equivalent to a deterministic Pushdown Automaton).
  • Chomsky Hierarchy: Distinguishes Type-3 (Regular Languages for tokens) and Type-2 (Context-Free Languages for nested statements and arithmetic expressions).
